# Git_test 练习仓库

这个仓库用来练习 Git 的基本用法。

## 最常用的命令

| 命令 | 作用 |
|---|---|
| `git status` | 查看当前有哪些改动 |
| `git add .` | 收集所有改动（暂存） |
| `git commit -m "说明"` | 打一个版本快照 |
| `git push` | 推送到 GitHub |
| `git pull` | 拉取 GitHub 上的最新版本 |
| `git log --oneline` | 查看提交历史 |

## 日常循环

改代码 → `git add .` → `git commit -m "做了什么"` → `git push`
